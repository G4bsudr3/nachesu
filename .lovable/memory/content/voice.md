**Regra de tratamento: sempre "você", nunca "tu".**

- Pronome sujeito: "você" (não "tu")
- Possessivos: "seu/sua/seus/suas" (não "teu/tua/teus/tuas")
- Conjugação verbal: 3ª pessoa singular ("você fala", "você fez", "você escolhe")
- "para você" / "pra você" (não "pra ti")
- "com você" (não "contigo")

**Por quê:** core memory determina assim. O project knowledge antigo dizia "tu não você" mas tá desatualizado e não vale mais. Em qualquer conflito entre core e project knowledge, core ganha.

**Exceções:** conteúdo já submetido por usuários (FBI responses, cartas publicadas). Não reescrever conteúdo histórico.

**Tom segue igual:** lowercase, sem em-dash, sem hashtags, frases curtas, frattz vibe, microcopy embutido.

**Carta de arquétipo (template):**
```
oi [nickname],

você é [arquétipo] [emoji].

[1-2 frases de superpoder, puxando respostas específicas].

[1 frase de sombra].

[próximo movimento concreto pra semana].

vai lá e cria.
```
